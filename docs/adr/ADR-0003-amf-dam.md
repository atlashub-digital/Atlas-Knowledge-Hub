# ADR-0003 — AMF retains editorial and publication authority (PROPOSED)

- Date: 2026-10-10
- Existing AMF rule: Notion editorial, GitHub technical, Drive master binaries, Factory Postgres run/approval/delivery.
- AKH proposal: read-only, permissioned pointers and extracted metadata; not a parallel creative approval scheduler.
- Alternatives: centralized DAM takeover, full media mirroring, no DAM integration.
- Gating: authorized AMF service contract, media rights taxonomy, exact artifact_version lookup, revocation demonstration.
- State: **proposed AKH integration; preserves observed AMF canonical architecture**.
