# Security and vulnerability disclosure

**Current stage:** reference design, no production deployment. Do not connect this prototype to actual clients, medical records or personal devices.

For vulnerabilities, use private GitHub Security Advisories / repository's private reporting functionality where enabled, or the approved internal security escalation path. Do **not** publish working exploits, credentials or sensitive customer screenshots in public issues.

Public repo controls: all test data must be synthetic; keep cloud tokens, private endpoints and deployment metadata out of Git and GitHub Actions logs. Security controls in this repository are examples and require end-to-end penetration tests and authorization review before any production use.
